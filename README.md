# Copilot

Dieses Repository enthält eine sichere, nachvollziehbare Grundlage zur Modernisierung alter Router/Repeater-Firmware-Prozesse.

## Enthalten

- `docs/re300_firmware_plan_de.md` – deutschsprachiger Plan für eine sichere Modernisierung eines TP-Link RE300 V1.
- `scripts/verify_tp_link_firmware.sh` – Skript zur Integritätsprüfung und reproduzierbaren Extraktion eines offiziellen Firmware-ZIPs.

## Schnellstart

```bash
./scripts/verify_tp_link_firmware.sh /pfad/zur/RE300_V1_211126.zip
```
